# CareerPlus website

Multi-page Next.js website for CareerPlus, built with:

- Next.js App Router
- TypeScript
- Tailwind CSS
- Mobile-first responsive UI
- Vercel-ready project structure

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm run start
```

## Site structure

- `/` — Home
- `/services` — CareerPlus DFY
- `/how-we-work` — Process
- `/contact` — Contact
- `/en` — English placeholder route

## Contacts and social links

Email, Telegram, Instagram, Threads, Calendly, Formspree, and Whop links are in `lib/site.ts`.
